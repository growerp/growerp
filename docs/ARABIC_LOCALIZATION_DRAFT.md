# GrowERP: إضافة العربية، نسخة تطوير جزئية غير منشورة

الحالة: غير مكتمل للتسليم الإنتاجي. لا يوجد نشر أو دفع إلى GitHub، ولا معاينة تشغيل مثبتة.

المصدر: https://github.com/growerp/growerp
نسخة الأساس: 3c3e20339643cd24ee913f07d6fd64e892f6e5d1

## ما تغير
- إضافة «العربية» إلى قائمة اختيار اللغة وإضافة ar إلى اللغات المدعومة.
- ملف core_ar.arb يغطي 459 رسالة أساسية، مع الحفاظ على الأسماء التقنية وأمثلة الأرقام والمتغيرات.
- تفعيل المورد العربي في جميع حزم الترجمة الـ25. ملفات الحزم الأخرى فارغة من الرسائل عمدًا؛ يستخدم مولد Flutter الإنجليزية الأصلية للنصوص غير المترجمة. هذه ليست ترجمة كاملة للوحدات.
- استخدام RTL الأصلي من Flutter عبر GlobalWidgetsLocalizations. حفظ اللغة واستعادتها يعتمد على آلية LocaleBloc الحالية دون تغييرها.
- إصلاح محاذاة start/end للجداول المشتركة مع الحفاظ على left/right الصريحة، وعكس موضع أزرار إغلاق ثلاث نوافذ مشتركة باستخدام PositionedDirectional.
- إضافة فحص ARB بنيوي و8 حالات اختبار Flutter للغة المحفوظة، وصيغ الجمع العربية، وRTL في قياسين وحالتين لونيتين، واتجاه الجداول.

## تحقق نُفّذ
- نجح python flutter/tool/check_arabic_localizations.py: 25 موردًا، مفاتيح الواجهة الأساسية، متغيرات الرسائل، تسجيل اللغة وخيار القائمة.
- نجح git diff --check.
- نجح تنسيق ملفي اختبارات Dart، مع تحذير تعذر حل flutter_lints لعدم إعداد اعتماديات المشروع.

## ما لم يُتحقق منه
- لم تعمل اختبارات Flutter بعد. تنزيل SDK واعتماديات أداة Flutter نجح، لكن بناء الأداة توقف مرتين برمز 137 (إنهاء العملية بسبب موارد البيئة)، بما في ذلك محاولة تقليل ذاكرة Dart.
- لم ينجح بناء تطبيق ولم توجد معاينة فعلية. لا يوجد ادعاء بتشغيل التطبيق أو نجاح السيناريوهات أو خلو الشاشات من التداخل.
- اختبارات اللغة الجديدة محدودة وليست اختبارًا كاملًا لـTopApp أو قائمة اللغة الحقيقية أو الوحدات الفرعية.
- باقي نصوص الوحدات، الرسائل الخلفية والبريد، النصوص الثابتة، الأرقام والعملات والتواريخ وتخطيطات جميع الشاشات تحتاج استكمالًا وفحصًا. لم تتغير قاعدة البيانات أو الحسابات أو التكاملات.

## تطبيق الحزمة في نسخة تطوير
من جذر نسخة المستودع عند نسخة الأساس المذكورة:

    git apply --check growerp-arabic.patch
    git apply growerp-arabic.patch
    python flutter/tool/check_arabic_localizations.py
    cd flutter
    flutter pub get
    for package in packages/*; do
      if [ -f "$package/l10n.yaml" ]; then
        (cd "$package" && flutter gen-l10n) || exit 1
      fi
    done
    cd packages/growerp_core
    flutter test test/l10n

قد يتطلب المشروع بقية خطوات توليد الملفات الموضحة في تعليمات مستودعه قبل بناء تطبيق admin. ملفات Dart المولدة للترجمة غير مرفقة لأنها مستثناة في المستودع وتُولد من ARB.

قبل الدمج أو النشر يجب تشغيل الاختبارات والبناء وفحص اختيار العربية ثم إعادة فتح التطبيق، تبديل الإنجليزية/العربية، النوافذ والجداول والقوائم والتمرير على الهاتف والتابلت والديسكتوب وحالتي Light/Dark. يجب استكمال الترجمة للوحدات المطلوبة ومراجعة المصطلحات مع المستخدم.
