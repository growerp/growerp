# GrowERP — First 10 Customers Plan (90 days)

**Status:** Plan of record for **Oct 20, 2026 → Jan 17, 2027**. It replaces the 90-day calendar (§9) of [GrowERP_Marketing_Sales_Plan.md](./GrowERP_Marketing_Sales_Plan.md) until the exit criteria below are met.
**Audience:** General SMB owners, reached through existing customers/clients and LinkedIn.
**Principle:** Do things that don't scale. Talk to people, set them up by hand, and learn from every one.

---

## 1. Why this plan

GrowERP is feature-complete for a small business: 10 apps, 6 platforms, AI agents, and a marketing/outreach toolset. It has **about 0–5 real users**.

The master marketing plan is a *scale* plan. Before it can run, it needs nine system enhancements: a drip engine, a pipeline board, dashboards, checkout, and more. At this stage those are premature. Every week spent building them is a week not spent with customers. Without users we also don't know which of them matter.

So for 90 days:

- **Feature freeze.** Only bug fixes and fixes for friction a real customer hit. Time split: about **80% selling and onboarding, 20% product**.
- **Manual first.** Set up each customer's tenant, import their data and train them personally.
- **Let the market choose the niche.** Start broad (general SMB) through the warm network. After the first 10–15 conversations, sharpen the message for the industry that pulls hardest.

### Success at day 90

| Goal | Target |
|---|---|
| Companies actively using GrowERP weekly | **10** |
| Paying (any amount) | **3** |
| Written/video testimonials | **3** |
| Published case study | **1** |

**The one metric to watch: weekly active companies.** A company counts as active if it did real work in GrowERP that week, such as an order, an invoice, a booking or a payment. Signups and page views don't count.

## 2. The offer — "Founding Customer"

Limited to **10 companies**. The cap is real and creates urgency.

**They get:**
- A free concierge setup: we create the tenant, configure the company, and import products, customers and opening balances from their spreadsheets or old system.
- Six months free, then **50% off for life**.
- A direct line to the founder; their requests are prioritized on the roadmap.

**We ask:**
- A 15-minute feedback call each week during the first month, then monthly.
- Honest feedback, plus a testimonial and permission to name them, *if* they are happy.

Publish this as a single page on the website, built with the website builder, with one call to action: **"Book a 20-minute call"**. A plain calendar link is fine; no booking feature needs to be built.

## 3. Target list — 100 names

Build it once in week 1 and keep it in the **GrowERP CRM as Leads**. This dogfoods existing features only.

| Tier | Source | Count | Approach |
|---|---|---|---|
| **Hottest** | **Past trial users** (signed up, then stopped) — they are on the weekly mailing list | all | Personal plain-text email from your own address, *not* the newsletter: "what stopped you?" (message 12). Every answer is a friction to fix, and a reason to write back when it's fixed |
| Hot | **Weekly mailing list** (~1000 subscribers) | 1000 | One newsletter issue announcing the founding-customer round (message 11), then a short mention in every issue. Replies become leads |
| Warm | Past clients, former colleagues, people who know your work | 30–40 | Personal message or phone call; ask for a referral even if they're not a fit |
| Lukewarm | 1st/2nd-degree LinkedIn connections who own or run an SMB (5–100 staff) | 50–60 | Personal LinkedIn message that mentions something specific about them |
| Partners | Accountants, bookkeepers and IT consultants in your network | 5–10 | They see many SMBs; offer a referral fee or free partner tenant |

Note for each lead: industry, current tools (Excel, QuickBooks, Odoo, paper…), and the pain they mention.

## 4. Weekly rhythm

Repeat every week. Keep it consistent; don't do bursts.

| Day | Activity | Target |
|---|---|---|
| Mon–Thu | Personal messages: written one by one, no automation, no mass templates ([templates](./GrowERP_First_10_Customers_Messages.md)) | **20 / week** |
| Mon–Thu | Discovery calls of 20 minutes (see script below) | **3 / week** |
| Tue + Thu | LinkedIn posts (see content mix) | **2 / week** |
| Any | Onboard new founding customers personally; check in with active ones | all |
| Fri | Review the scorecard (§8); fix the **#1 friction** a customer hit this week | 1 fix |

**Funnel math:** 20 messages → ~3 conversations → ~1 new active company per week. That gives roughly 10 in 13 weeks after a 2-week prep. If conversations fall below 2 a week, change the message, not the volume.

### Discovery call script (listen first, demo second)

1. What does a normal week look like? Which tools do you use to run the business?
2. What is most painful or slow right now? What does it cost you, in hours or mistakes?
3. What have you tried? Why didn't it stick?
4. *(Only if there's a real pain)* Show only the part of GrowERP that solves that pain. Keep it to 5 minutes.
5. Offer founding-customer status. Book the setup session right away.

Log the answers on the lead. In week 7 these notes decide the niche.

### LinkedIn content mix

- **Build in public:** what was fixed this week and why ("a customer couldn't find X, now it's one click").
- **Short screen videos (≤60 s)** of one real task: an invoice in 60 seconds, a stock check, an AI agent drafting a campaign.
- **Customer stories:** once there are any, with permission.
- **Opinion:** "Why small businesses don't need SAP", "spreadsheets vs. ERP — the real cost".

Every post ends with a soft call to action: *"Looking for 10 founding customers — DM me."*

## 5. Phases

### Weeks 1–2 (Oct 20 – Nov 2) — Prep
- [ ] Walk the full path yourself on production, the way a stranger would: website → signup → first product → first invoice. Write down every hesitation and fix the worst 3.
- [ ] Build the 100-name target list in the CRM.
- [ ] Export the past trial users (signups without recent activity) from the support app / mailing list; send each one message 12 personally (spread over the 2 weeks, ~10 a day). Log every reason in the CRM.
- [ ] Publish the founding-customer page and add a calendar link for the 20-minute calls.
- [ ] Make a 1-page PDF: "What GrowERP replaces" (spreadsheets, invoicing tool, stock list, CRM), with before/after.
- [ ] Record 3 short demo videos: invoice, inventory, AI agent.
- [ ] Prepare a data-import routine for customer spreadsheets (products, customers, suppliers), so onboarding takes hours, not days.

### Weeks 3–6 (Nov 3 – Nov 30) — Warm outreach
- [ ] Week 3 newsletter issue: the founding-customer round (message 11). Answer every reply personally within a day.
- [ ] Past trial users whose reason is fixed: send message 14.
- [ ] Message every warm contact first. Ask each one: *"Do you know 2 business owners still running on spreadsheets?"*
- [ ] Start the LinkedIn rhythm.
- [ ] Approach the partners (accountants/bookkeepers).
- **Target:** 15 conversations, 5 companies onboarded.

### Weeks 7–10 (Dec 1 – Dec 28) — Narrow
- [ ] Analyze the discovery notes: which industry has the most pain, the fastest yes, and the best fit?
- [ ] Rewrite the homepage headline and LinkedIn targeting for that industry. Keep the rest general.
- [ ] Write case study #1 with the happiest customer.
- **Target:** 8 active companies. Expect a slower holiday period.

### Weeks 11–13 (Dec 29 – Jan 17) — Convert & compound
- [ ] Ask every happy customer for a testimonial and 1 referral.
- [ ] Start charging the first customers. A manual invoice or Stripe payment link is fine; no checkout build.
- [ ] Do the one-time developer launch (§6).
- [ ] Hold the 90-day retro (§9).
- **Target:** 10 active, 3 paying, 3 testimonials.

## 6. Supporting channels (low effort, in parallel)

- **Open-source launch, done once:** polish the GitHub README (screenshots, a 1-command Docker demo, a clear "who it's for"). Then post to r/selfhosted, r/flutterdev and Show HN in the same week. This gives a spike of developer attention and credibility, plus a few self-hosters who may become partners.
- **App stores:** these are already live. Just make sure the store descriptions link to the founding-customer page.
- **Partners:** one accountant who recommends GrowERP can bring more customers than a month of posts.

---

## 7. What NOT to do these 90 days

- ❌ New apps, verticals or big features. The product is ahead of the market.
- ❌ The system enhancements in §10 of the master plan: drip engine, pipeline board, dashboards, checkout, booking.
- ❌ Paid ads. There's no proven message or conversion path to pay for yet.
- ❌ Automated mass outreach through `growerp_outreach`. At this stage it risks the LinkedIn account and the brand; personal beats volume.
- ❌ Measuring signups or impressions as success. Only weekly active companies count.

## 8. Weekly scorecard

Keep it in a spreadsheet or GrowERP notes and fill it in every Friday.

|---|---|---|---|---|---|---|---|
| 1 (Oct 20) | | | | | | | |
| 2 | | | | | | | |
| 3 | | | | | | | |
| … | | | | | | | |
| 13 (Jan 12) | | | | | | | |

**Warning signs:**
- Messages are sent but conversations stay below 2 a week → the message or target is wrong. Rewrite it; ask contacts why they didn't reply.
- Customers are onboarded but don't stay active → there's a product or onboarding problem. Watch them use it, live.
- Customers are active but nobody pays → value or price is unclear. Ask directly: "What would make this worth €X/month?"

---

## 9. Exit criteria → back to the master plan

When **10 companies are active weekly**, or at the day-90 retro, whichever comes first:

1. Review the scorecard and discovery notes.
2. Re-prioritize the master plan's §10 enhancements based on **friction customers actually hit**, not on assumptions.
3. Choose the next 90 days: either scale what worked (more volume, a niche landing page, the outreach automation), or run a second founding round in the chosen niche.
