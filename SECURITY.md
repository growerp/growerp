## Reporting a Vulnerability

Use this section to tell people how to report a vulnerability.

The standard way to report a security vulnerability follows RFC 9116 (security.txt) 
for discovery, coordinated vulnerability disclosure (CVD) guidelines, 
and industry frameworks like the OWASP Vulnerability Disclosure Cheat Sheet Series.
